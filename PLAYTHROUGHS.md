# Three start-to-ending playthroughs

Each route lists every choice from **start** through **graduation** (Passage 19). Final scores and ending names come from the game’s `setup.ending()` logic.

---

## Route 1 — The Purposeful Commodore

**Theme:** Honesty, relationships, and meaningful work over prestige.

| Passage | Choice |
| --- | --- |
| start | Begin the countdown |
| family | Tell the truth: "I am still figuring it out." |
| invitation | Call a friend and go together |
| resume | Use only your real experience |
| vault | Approach the three elevators |
| choose | Enter the Courtroom (Law) |
| careerLaw | Question the recruiter about the case |
| submitted | Enter the waiting room |
| waiting | Help a nervous friend prepare |
| interview | Tell a truthful story about failure *(prepared)* |
| rejection | Answer the blocked call |
| offer | Reject the offer completely |
| check | Continue with your record intact *(honest résumé)* |
| twoOffers | Choose meaningful work |
| emergency | Go home immediately |
| betrayal | Delete the file and warn your friend |

**Final scores (approx.):** Career 3 · Integrity 29 · Wellness 12  
**Ending:** **THE PURPOSEFUL COMMODORE** — modest beginning, values-aligned work.
